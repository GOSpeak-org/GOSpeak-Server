派生规则：三套深色分别复用对应浅色的色相（冷青 210 / 丁香 310、暖橙 45 / 琥珀 85、松绿 155 / 青瓷 170），只提明度、降彩度； 背景 / 卡片 / 浮层分三档，描边在深色下比 card 更亮（≈1.23:1），文字按对比度对齐（浅 60%/42%，深 56%/38%）。

使用方式：设置 → 外观。关闭深色模式可选 Acid / Aurora / Ember / Forest；打开深色模式可选 Dark / Midnight / Cinder / Grove，分别记忆。
